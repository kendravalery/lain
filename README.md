# LAIN

A small experimental web project inspired by the visual atmosphere of Serial Experiments Lain.

## Notes
This project is primarily an experiment in:
- Vanilla JavaScript
- CSS animations
- HTML5 Audio
- Timed interactions

It intentionally uses no frontend framework to keep the implementation close to the native web APIs.
